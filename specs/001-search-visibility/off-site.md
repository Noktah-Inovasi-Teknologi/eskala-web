# Off-site checklist (FR-024, G-12, G-25)

Recommendations, not launch requirements. Each one is **free**, with no paid listings (G-25). Chatbots answer from what *other* sites say about a business, so these matter as much as the site itself for being named in ChatGPT, Gemini and Perplexity.

The rule for all of them: **say the same thing everywhere.** Use the same name (Eskala), the same one-line description, the same link (https://eskala.id) and the same contact. A chatbot trusts a description that matches across sources.

**The one-line description to reuse** (from the glossary and the site):
> Eskala adalah partner digital marketing dan komunikasi kesehatan untuk klinik pratama dan utama, rumah sakit, serta dokter umum maupun spesialis di seluruh Indonesia.

Never name Noktah in these profiles (constitution IV). Never mention a price other than the two starting prices.

**Left off on purpose**
- Google Business Profile and Bing Places: they expect a physical location, and Eskala's positioning is national (G-12 allows leaving them off).
- Paid directory listings and sponsored articles (G-25).
