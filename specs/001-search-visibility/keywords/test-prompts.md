# Test prompts (FR-009, SC-008)

Questions a clinic owner, a hospital marketing manager or a doctor might ask a chatbot. Use them for the baseline before Release 1 goes live, again 8 weeks after, and in the monthly review. Ask each one in a **new chat**, logged out or in a private window where possible, and with no earlier mention of Eskala. Record the results in [../baseline.md](../baseline.md).

The list is fixed so results stay comparable: add new prompts at the end and never reword an existing one.
